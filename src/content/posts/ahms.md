3. 密码学中aes和des的区别

> 分组大小不同，密钥长度不同，结构不同，当时她想继续深问来着，但是这一块确实不太熟，就把锅甩给了读研专门读对称密码的队友了，说自己主要擅长rsa部分

| 特性     | DES                      | AES                  |
| -------- | ------------------------ | -------------------- |
| 分组大小 | 64 位                    | 128 位               |
| 密钥长度 | 56 位（实际64但8位校验） | 128 / 192 / 256 位   |
| 结构     | Feistel结构              | SPN（代换-置换网络） |
